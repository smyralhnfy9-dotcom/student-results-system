# Student Results Management System | نظام إدارة نتائج الطلاب

نظام ويب بـ HTML + CSS + JavaScript فقط (بدون مكتبات) لإدارة وتحليل نتائج الطلاب.

## التشغيل
افتح `index.html` في المتصفح مباشرة. افتح Console بالضغط على F12 لرؤية التقارير.

## المميزات
- إضافة / تعديل / حذف الطلاب مع التحقق من البيانات ومنع تكرار رقم الجلوس.
- حساب المتوسط (`reduce`) والتقدير A–F (`if/else`) والنتيجة (`&&`): ناجح إذا المتوسط ≥ 50 والحضور ≥ 75%.
- المتعثرون (`filter`): المتوسط أقل من 50.
- لجنة الرأفة: `filter` (40–49) ثم `map` (+5 بحد أقصى 100) ثم `reduce` للمتوسط، مع منع القسمة على صفر. للعرض فقط ولا تغير النتيجة الأصلية.
- بحث وفلترة، حفظ في `localStorage`، طباعة التقارير، تصدير CSV، وطباعة التقارير في Console.
- 4 طلاب تجريبيين عند أول تشغيل فقط (يمكن حذفهم).
